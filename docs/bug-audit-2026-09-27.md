# 训练与云算力缺陷排查（2026-09-27）

## 范围

检查本地 / Colab / Hugging Face 的启动互斥、取消、退出清理、账号管理、任务状态、计时和结果下载；在浏览器执行一次本地训练启动及顶部停止操作。

## 已修复

1. **HF 取消请求被当成资源已释放**：保留 `stopping`，等待平台终态确认；确认前保留断开入口。
2. **批量停止遇到首个失败后漏停后续任务**：逐个尝试，保留每项错误和未释放状态。
3. **实验室退出漏停 HF**：正常退出及异常退出清理均尝试两个平台；一个平台失败不阻挡另一个。
4. **Colab 启动/轮询/下载期间取消可能被覆盖**：持久记录取消意图；每个阻塞调用之后检查，不再继续启动训练。正常退出等待分配线程清理，超过等待上限仍报告未确认释放。
5. **跨标签页、跨平台重复启动**：服务端共享提交锁，在调用云 API 之前预留；本地配方重训入口也受此检查。前端加即时提交保护。
6. **活动 HF 任务失去账号控制**：活动任务存在时拒绝删除或替换现有 Token；账号操作与任务提交共用锁。
7. **账号查询故障阻挡其他平台状态**：任务和账号分别更新，一个平台失败不清空另一个平台的已知任务。
8. **停止反馈不明确**：HTTP 失败打开任务面板；未确认释放时明确提示待确认；停止按钮不再等待余额刷新。
9. **已结束任务计时继续增长**：记录释放时间，历史计时固定；资源已释放但仍下载结果的任务不再被当成占用算力。
10. **HF 容器不一定存在 `/content`**：远程脚本递归创建工作目录。
11. **下载瞬时故障被误判为训练失败**：计算资源已释放后继续重试结果下载，只有远程训练失败才按训练失败处理。
12. **常用动作中文遗漏**：补齐五个默认动作按钮的中文名称和提示，保留原始训练命令。
