# Colab 防扣费说明

代码位置：`microduck_local/src/microduck_local/colab_jobs.py`。回归测试：`microduck_local/tests/test_colab_jobs.py`。

## 什么情况会自动结束任务

| 情况 | 触发条件 | 结果 |
|---|---|---|
| 时长上限 | 从分配运行时起，达到 `maxMinutes`（默认 180，可设 5–720） | 保存进度、下载、释放，状态 `stopped` |
| 计算单元上限 | 消耗达到 `maxCcu`（可选） | 同上 |
| 训练卡死 | `train.log` 15 分钟没有更新 | 尝试保存、下载、释放，状态 `failed` |
| 环境安装卡死 | `setup` 阶段超过 25 分钟 | 释放，状态 `failed` |
| 训练进程未启动 | 3 分钟没有 `status.json` | 释放，状态 `failed` |
| 无 GPU | 3 次探测都没有拿到设备信息 | 不开始训练，释放 |
| 无法联系云端 | 连续 15 分钟查询失败 | 尝试释放，状态 `failed` |
| 会话被回收 | CLI 报告会话丢失 | 立即结束，状态 `failed` |

保存最多等待 7 分钟；超时后也会释放。检查点按 `save_interval`（最多 250 次迭代）保存，所以中途停止可能损失最后一段进度。

## “已释放”的含义

`released=true` 只在 Google 的 `colab sessions` 确认会话消失后才会写入。`colab stop` 退出码为 0 不算数，因为它对本地没有记录的会话同样返回 0。无法确认时保持 `released=false`，界面显示“可能仍在计费”，并阻止启动新任务。

后台对账器有未释放任务时每 60 秒检查一次，否则每 5 分钟检查一次；释放重试按指数退避，最长间隔 10 分钟。

## 保护不到的情况

- **电脑合盖或关机。** `caffeinate -i` 只阻止空闲休眠。运行时没有用户的 OAuth 令牌，无法自行释放。此时云端 runner 会在时长上限后 5 分钟自行停止训练并保留结果；运行时要等电脑恢复后才能释放，或由 Google 回收。
- **授权在任务运行期间失效。** `colab stop` 需要 OAuth，无法释放时界面会提示；请重新连接账号，或在 Colab 网页的“代码执行程序 → 管理会话”中终止。
- **不属于任何任务的会话。** 面板只列出并由你确认释放，因为它可能是你自己在网页打开的 Notebook。
- **Hugging Face 任务。** 本文的上限和对账只覆盖 Colab。

## 真实 GPU 验收步骤

回归测试和界面验证都使用假 CLI。以下步骤需要在重新授权后手动完成，会消耗免费额度或计算单元：

1. 在云算力面板重新连接账号，确认“Google 侧活动会话”为 0。
2. 选择“官方行走”、T4、100 次迭代、时长上限 30 分钟，确认阶段依次经过安装依赖、训练中、导出模型、下载结果，进度条和 GPU 占用有数字。
3. 结束后确认有 ONNX 和检查点，活动会话回到 0。
4. 再启动一次，在训练中点“保存并断开”，确认取回检查点且活动会话回到 0。
5. 再启动一次，在训练中执行 `kill -9` 结束 `duck-lab` 后重新启动，确认任务被接管并能正常结束。
6. 用 4096 环境跑一次，确认 T4 显存足够；不够时调低环境数。
7. 观察一次超过 1 小时的运行，确认运行时不会被 Google 中途回收。

冒烟成功只证明链路可用，不证明策略学会了动作。部署前仍需按 `microduck_local/AGENTS.md` 渲染并评估。
