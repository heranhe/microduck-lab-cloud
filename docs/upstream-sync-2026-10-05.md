## 升级

1. 已有训练先完成或保存停止，再更新 `main` 并重启服务。
2. 在 `microduck_local` 执行 `uv sync --locked`；在 `duck-viewer` 执行 `npm ci` 和 `npm run build`。
3. 首次使用或已经下载过 MOSS，都执行 `uv run fetch-robot moss` 补齐当前资源。
4. 按 README 重启后端与前端。原有训练目录、模型和训练方案无需迁移。
